# 지표 슬라이드 틀 (숫자만 채우면 되는 형태)

> 담당 AI B. 출처: `README.md` 12장. 코드로 만들 때는 `metrics.py` 의 `collect(...).to_slide()` 가 같은 구조를 뽑는다.
> **발표 순서 5번 "지표와 한계"에 이 한 장을 쓴다** (`../../docs/06-demo-and-metrics.md` 6장. 1 설문·문제 → 2 차별점 → 3 시스템 구조 → 4 데모 → **5 지표와 한계**).

## 쓰는 방법

- 14:30 기능 동결 뒤 30분(14:30~15:00) 안에 값 칸만 채운다.
- **값이 없으면 `미측정` 이라고 적는다.** 빈칸으로 두거나 0, 100% 로 채우지 않는다. 측정하지 않은 것을 달성한 것처럼 보이게 만들면 발표에서 하는 거짓말이 된다.
- 달성 칸은 `달성` / `미달` / `—`(미측정) 셋 중 하나다. 미측정은 달성도 미달도 아니다.
- 목표 칸은 이미 정해져 있다. 당일 고치지 않는다.
- 코드를 돌릴 수 있으면 `python3 -c "from ai.judgment.metrics import collect; print(collect(...).to_slide())"` 로 같은 표를 받는다.

## 지표

| 지표 | 값 | 목표 | 달성 | 누가 주는 값인가 |
| --- | --- | --- | --- | --- |
| 근거 없는 조건 건수 | | 0건 | | **AI B**. 점검표(README 11장)로 대표 프로필 5개 × 예외 흐름 3개를 13:00~14:30에 수동 점검한 건수 |
| 인용 검증 통과율과 제거 건수 | | 통과율 100% | | **백엔드B**. 검증 통과 발췌 수와 제거된 발췌 수. 통과율 = 통과 ÷ (통과 + 제거). 둘 다 0이면 `미측정` |
| 판정 평가 J1~J8 결과 | | 7개 이상, unmet 오판 0건 | | **AI B**. `python3 -m ai.judgment` 또는 `scoring.evaluate(...)` 의 통과 수와 `unmet` 오판 수 |
| 추천 정확도 | | 80% 이상 | | **백엔드A**. 대표 프로필 상위 3개 중 정답 정책 비율. 정답셋은 AI 담당에게 비공개 |
| 응답 시간 | | 첫 카드 2초, AI 설명 15초 | | **백엔드B**. 데모 경로 실측. 첫 카드는 폼 제출→카드 표시, AI 설명은 메시지 전송→답변 완료 5회 최댓값 |

## 한계

| 한계 | 내용 |
| --- | --- |
| 커버리지 | 검수된 20~30건뿐. 전국 실시간 수집이 아니다 |
| 판정의 성격 | 최종 자격 판정이 아니다. 신청 가능성과 근거를 보여줄 뿐이다 |
| 설문 | 29명 편의표집. 비율을 시장 전체로 일반화하지 않는다 |
| 데이터 갱신 | 수동. 확인일로부터 14일이 지나면 재확인 필요로 표시하는 것이 현재 대책이다 |
| 접근성 | 기준을 지켰지만 보조기술 수동 테스트와 전문가 검토는 하지 못했다 |

> 한계를 먼저 말하는 쪽이 질의응답에서 유리하다. 심사위원이 먼저 지적하면 방어가 되고, 우리가 먼저 말하면 판단으로 보인다.

## 주의 (해당되면 적고, 아니면 줄을 지운다)

- 판정 평가 케이스가 아직 실제 공고 문장이 아니다 → **J1~J8 수치를 발표에 쓰지 않는다** (`scoring.Report.placeholder_cases` 가 0이 아닐 때)
- 용량 부족이 있었다 → **데모는 데모 모드로 돌린다** (`judge.JudgeStats.overloaded` 가 0이 아닐 때)
- 미측정 지표가 n개 있다 → 어느 지표인지 이름을 적는다

## 질의응답 대비 (슬라이드에는 넣지 않고 손에 들고 있는 메모)

| 질문 | 답 |
| --- | --- |
| 인용 검증 통과율이 낮은데 왜 느슨하게 풀지 않았나 | 문자열 대조가 실패하는 방향이 안전하다. 통과하지 못한 조건은 미확인으로 내려가고 발췌가 화면에 나가지 않는다 (README 6장) |
| 근거 없는 조건을 어떻게 셌나 | 정책별로 원문에 있는 조건 목록을 미리 적어 두고, 화면에 나온 조건이 목록에 없으면 1건으로 센다. 인용 검증기가 잡지 못하는 것을 잡는 점검이다 (README 11장) |
| 미측정 칸은 왜 비어 있나 | 측정하지 않았다. 0이나 100%로 채우지 않는다 |
