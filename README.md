팀원이 서로 다른 OS를 쓰기 때문에 문자열이 어긋나는 문제가 생긴다. 특히 공고 원문(`raw_text`)이 조금이라도 달라지면 인용 검증이 전건 실패하고, 모든 정책 카드가 "확인이 필요해요"로 떨어진다.

두 계층으로 막는다.

- **`.gitattributes`** — 저장소 안 텍스트는 항상 LF로 저장·체크아웃한다. 개인 `core.autocrlf` 설정에 의존하지 않는다. 윈도우 전용 스크립트(`.bat` `.cmd` `.ps1`)만 CRLF를 유지한다.
- **`ai/citation/normalize.py`** — 런타임 방어. 유니코드 NFC 통일(macOS의 한글 자모 분해형 대응), BOM·제로폭 문자 제거, 비분리 공백·전각 공백 흡수.

git을 거치지 않는 경로(스프레드시트 붙여넣기, API 응답)가 있으므로 둘 다 필요하다.

정책 데이터를 CSV로 주고받을 때는 **UTF-8(BOM 없이)** 로 저장한다. 윈도우 Excel에서 "CSV UTF-8"로 저장하면 BOM이 붙는데, 정규화가 제거하긴 하지만 다른 도구에서 깨질 수 있다.

# 청년 공공지원제도 AI 에이전트

서울 거주 만 19~24세 대학생·취업준비생이 기본 정보를 입력하고 자기 상황을 말하면,
AI가 공식 공고를 근거로 받을 수 있는 지원제도를 바로 보여주고, 판정에 필요한 것만 되물으며,
신청까지 해야 할 일을 정리해 주는 대화형 서비스.

> 청년 지원제도를 위한 Perplexity. 모든 판정 문장에 공고 원문 각주가 달린다.

## 절대 깨지 않는 P0 세 가지

1. **원문 각주** — 판정 문장에는 반드시 공고 원문 발췌 각주가 붙는다. 각주 없는 판정 문장은 출력하지 않는다.
2. **판정을 바꾸는 후속 질문** — 상위 후보의 판정 상태를 바꾸는 정보만 묻는다. 없으면 묻지 않는다.
3. **즉시 1차 결과** — 폼 제출 직후 규칙 엔진 결과로 카드를 먼저 띄운다. AI 설명은 그 뒤에 스트리밍.

## 확정된 기술 결정

- 임베딩·벡터 검색 **미사용**. 정책 20~30건은 규칙 필터로 좁히고 공고 원문(`raw_text`)을 컨텍스트에 직접 투입한다.
- 명시 조건(나이·지역·신분·소득%·마감)은 규칙 엔진이, 문장형 예외 조건만 AI가 판정한다.
- 판정 상태 문구와 D-day는 **코드**가 붙인다. AI는 날짜를 계산하지 않고 상태를 새로 판단하지 않는다.
- AI 판정이 늦거나 실패해도 규칙 엔진 결과만으로 카드는 보인다.
- 세션은 서버 메모리에만 둔다. DB에 저장하지 않는다.

## 기술 스택

| 영역 | 결정 | 비고 |
| --- | --- | --- |
| 서버, 규칙 엔진, AI 모듈 | **Python** | `server/`, `rules/`, `ai/conversation/`, `ai/judgment/` 전부 |
| 프론트 | 미확정 (정적 내보내기 가능한 것) | S3에 정적 파일로 올라간다 |
| AI 모델 | **Claude 또는 GPT** (캠프 제공) | 호출 지점은 메시지 해석·예외 조건 판정·답변 작성 세 곳뿐. 호출부를 한 군데로 모은다 |
| 프론트 호스팅 | **S3** (캠프 제공) | 서버 사이드 렌더링 없이 단일 페이지 앱. API는 다른 오리진이라 교차 출처 허용이 필요하다 |
| 데이터 저장소 | 없음 | 세션은 서버 메모리에만 |

**파이썬이라 편해지는 것**: 서버가 주고받는 필드가 snake_case이고 파이썬 관습도 snake_case라
서버·규칙·AI 사이에는 이름 변환이 없다. 변환은 **프론트 경계 한 곳에서만** 일어난다.

**파이썬이라 조심할 것**: 규칙 엔진·AI 모듈·서버가 같은 언어라 경계가 흐려지기 쉽다.
폴더 소유권을 지키고, 규칙 판정 로직을 서버 쪽에 복사해 두지 않는다. 판정은 `rules/`에만 있다.

프론트 주소와 API 주소, 프로토콜은 10:30에 프론트와 백엔드B가 맞춘다.
자세한 내용은 `frontend/README.md` 9장, `server/README.md` 11장, `docs/00-overview.md`.

**백엔드 구현 기준은 Python 3.11 이상, FastAPI, Pydantic v2, pytest로 확정했다.**

- 프론트 프레임워크·UI 라이브러리·아이콘 세트 (프론트가 10:30까지, 정적 내보내기 가능한 것)

- Claude와 GPT 중 어느 모델을 쓸지, 호출 한도 (백엔드B가 10:30까지)
- 상태 배지 화면 문구 최종안 (프론트가 팀 외부 3명 확인 후 10:30까지)

## 금지 사항 (전원)

- 공고에 없는 금액·날짜·조건을 화면에 보여주지 않는다. 금액과 날짜는 데이터 필드에서만 가져온다.
- "대상입니다", "받을 수 있어요", "확실히", "무조건", "100%", "보장" 같은 확정 표현을 쓰지 않는다.
- 이름, 연락처, 주민등록번호, 계좌번호를 받거나 저장하지 않는다.
- 대표 프로필 정답셋을 AI A·B에게 공개하지 않는다. 이 저장소에 커밋하지 않는다. (`data/eval/` 참고)
