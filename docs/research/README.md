## 한계

- 출처의 내용은 라이선스 제약에 따라 요약·재구성했다. 정확한 수치와 조건은 각 문서의 링크에서 확인한다.
- LLM 제공사의 기능 지원 범위는 시점에 따라 바뀐다. 04번 문서의 비교 표는 10:30에 받은 모델의 공식 문서로 갱신한다.
- 명세 우선 개발의 효과, 문장 단위 스트리밍의 가독성 우위 등 일부 항목은 통제 연구를 찾지 못했다. 해당 절에 "근거 약함"으로 표시했다.
- 2026년 발행으로 표시된 일부 논문은 최신이라 후속 검증이 적다. 수치를 단독 근거로 쓰지 않았다.
